# DSH 资料库 · 把项目资料带进对话

给 **DeepSeek Harness** 的每个项目配一个资料库。文档、图片、表格或其他项目文件，都可以放在一起管理；聊天时开启资料库模式，让 AI 按需参考其中的原文件。

资料保存在你指定的本机目录，按工作区分开整理。你可以在「资料库」菜单里查看和管理所有库，也可以在对话中选择这次要用哪些资料。

## 功能

### 每个项目，资料各归各处

新工作区会自动建立独立资料库，已有工作区也可以创建或关联资料库。在统一管理页里，按库名、工作区或存储路径查找，按更新时间、名称或文件数排序，切换项目时也能找到对应的资料。

### 存在哪里，由你决定

第一次使用时，选择一个本机文件夹作为资料存储目录。导入会把文件复制到资料库，保留来源文件夹里的原件。每个库都有自己的目录，方便统一保存和备份。

### 文件和文件夹，都能批量导入

支持任意格式文件的原件存储。点击选择或直接拖入多个文件、整个文件夹，先在弹窗里核对清单，再确认导入。导入过程中可以查看进度和逐文件结果，同名文件分别保存。

### 需要参考资料时，在对话里开启

在资料库模式下，AI 可以查找已授权的文件，并按需打开相关原件，结合当前模型和可用文件工具回答问题。默认使用当前工作区关联的资料库，需要时也能为这次会话额外授权其他库；日常闲聊则可以切回通用模式。

### 哪些资料给 AI 用，随时可调整

文件可以单独纳入或排除 AI 参考，也可以下载原件、移入回收区或恢复。整理项目时，支持整库移入回收区、清空回收区，以及停用后删除资料库；永久删除前会要求输入名称确认。

## 安装

当前正式版为 **1.0.0**，适配 DeepSeek Harness `0.2.1-rc.3` 接口，声明兼容范围为 `>=0.2.1-rc.3 <0.3.0`，需要 Node.js ≥22.13.0。各宿主版本的验证情况见[验证记录](docs/validation.md)。

1. 从 [Releases](https://github.com/wuzeno/dsh-library/releases/latest) 下载 **`dsh-library-1.0.0.tgz`** 插件安装包。
2. 打开 DSH 的「插件」管理器，通过本地安装包入口安装并启用。如果宿主提供的是链接本地目录入口，先解压安装包，再选择其中包含 `package.json` 的 `package` 目录。
3. 完整退出 DSH，包括托盘里的后台进程，再启动并刷新页面。侧栏出现「资料库」就可以开始使用了。

升级时保留现有资料，先备份资料目录和 DSH profile，再安装新版本并完整重启。

## 首次使用

1. **选好存储位置。** 打开「资料库 → 存储与隐私」，选择或填写运行 DSH 的电脑上的本机绝对路径，点击保存。
2. **确认文件使用授权。** 在同一页面确认是否允许模型按需使用整份原文件。
3. **放入项目资料。** 新工作区会自动建库；已有工作区可以先创建或关联资料库，再拖入文件或文件夹，核对清单并确认导入。
4. **开始提问。** 在对话中开启资料库模式，确认参考范围，然后直接描述你的问题。

例如，可以试着问：“项目里有哪些参考文档？”或“请根据库里的需求文档，整理这次要做的功能。”

## 按需附件与隐私

资料先保存在本机，需要参考时，再由模型按授权范围打开相关原件。导入后即可管理文件，具体内容的读取由宿主、当前模型和可用工具完成；支持保存的格式与能够读取的格式有所区别。

使用云端模型时，打开文件可能将整份原件发送给模型，并留在会话附件和历史中。你可以关闭授权来停止后续交付；已经发送的内容仍保留在原会话中。请根据资料的敏感程度决定是否授权，存储目录也应放在 Git 仓库之外。

授权范围、附件交付和数据处理的详细说明见[使用细节与技术参考](docs/usage-reference.md#按需附件与隐私)及[安全说明](SECURITY.md)。

## 格式与边界

支持任意格式的原文件存储，文件夹可递归导入。单文件默认上限为 **50 MiB**，可在设置中调整为 **1–200 MiB**；每库最多 **2000 个文件**，包含回收区。

大批量导入、目录扫描和各类文件的使用方式，见[完整参数说明](docs/usage-reference.md#格式与边界)。

## 一键移入回收区

在资料库详情的「文件」页点击「全部移入回收区」，输入完整库名确认，即可把该库全部未回收文件移入回收区，包括已排除的文件。操作范围是整个库，与当前搜索或筛选无关；之后可以逐个恢复。

## 回收区永久删除

在「回收区」中，可以永久删除单个文件，也可以清空整个回收区。两种操作都会要求输入完整名称确认，确认后删除库内副本、释放对应空间。永久删除不可恢复，重要资料请先备份。

## 删除资料库

先停用资料库，再从详情页选择「删除资料库」。确认框会列出文件数量和本地目录，输入完整库名后，删除该库及其目录中的文件，来源文件夹里的原件保持原样。

删除中的异常处理与重试方式见[操作细节](docs/usage-reference.md#删除资料库)。

## 数据布局与备份

备份时，请同时保留**资料存储目录和 DSH profile**，这样才能保留原件以及资料库关联、授权等设置。修改存储根目录后，新建资料库会使用新位置，已有资料库继续保存在原处。

目录结构、元数据与恢复方式见[备份说明](docs/usage-reference.md#数据布局与备份)和[架构与恢复](docs/architecture.md)。

## 开发与发布

开发环境需要 Node.js 22.13+（建议 24 LTS）与 pnpm。

```sh
pnpm install --ignore-scripts
pnpm run test:all
pnpm pack --pack-destination release
```

参与开发可查看[贡献指南](CONTRIBUTING.md)、[发布清单](docs/releasing.md)和[验证记录](docs/validation.md)。实现细节另见[技术参考](docs/usage-reference.md#开发与发布)。
