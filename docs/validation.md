# 验证记录与已知边界

## 当前公开版本：1.0.0

目标接口：DSH `0.2.1-rc.3`；声明兼容范围见 package.json。自动测试、用户截图和完整宿主联调是不同层次的证据，不相互替代。

### 发布前检查（2026-10-27）

- 检查版本、后端版本、bundle、locale、图标和 JavaScript 语法；核对包清单和 SHA-256。
- 整库删除安全加固：先持久化不可恢复的删除意图；中途失败不允许恢复残缺库；无法准确统计部分删除数量时返回未知而非虚假计数；续删核对目录身份。
- 阻止在已有库目录内配置/建立新库；删除前独立检查其他登记库，防止递归删除连带影响其他库。
- 会话最多 8 库的限制包含默认库。
- 自动测试仅操作合成临时数据，不删除用户正式资料。安全加固与客户端续删提示后的本地完整运行：256 项，254 通过、2 跳过、0 失败；生产依赖审计未发现已知漏洞；未运行的平台不计为通过。

### 既有验证证据

- 版本号与定位统一前，本地 Windows / Node 24 完整套件为 246 项：244 通过、2 跳过、0 失败。此为历史基线，不是安全加固后的最终测试数量。
- 已有 store、HTTP、Host mock 与 Client VM 契约测试覆盖默认库/跨库、整份原文件同意、通用模式、撤销竞态、回收/恢复/永久删除、批量导入预算和旧后端能力缺失。
- 文件夹遍历、导入确认弹窗、服务端错误及停止后续上传有契约测试；VM 测试不是浏览器视觉验收。
- Windows 目录 junction 拒绝有回归；部分文件符号链接测试受进程权限限制会跳过，必须读取实际 skip 原因，不能算作通过。
- 用户提供的截图支持侧栏菜单、管理页、会话入口和范围弹窗已渲染。公开展示副本已遮盖本机存储路径，不包含私人原件、测试答案、配置或凭据。
- 历史 0.1.x 解析器测试不代表 1.0.0 会预解析、OCR 或建立全文索引；当前 store 不调用历史解析模块。

## 仍需独立实机核验

1. 完整退出 DSH（含托盘）后更新插件，核对新 Host 与 Client 同时生效；网页刷新不能保证后端已重载。
2. 用无敏感样本检查 TXT、PDF、Word、表格、演示与图片：`library_files` → `library_open` → 原生 file/image block → 宿主只读投影 → 文件工具/skills/视觉读取；错误时诚实说明限制。
3. 检查未同意、撤销、通用模式、跨库未授权、fork/新会话、排除、回收、停用和异步交付中的授权变化，不能越权。
4. 用独立临时库验证停用→删除→重启持久性、取消、错误确认名、部分失败与重试。不要拿正式资料做破坏性验收。
5. 验证真实浏览器文件夹手势、下载、主题、窗口尺寸、断连恢复，以及多个宿主版本的兼容性。

云端模型可能接收整份原文件；关闭同意不能撤回历史附件或模型已见内容。本项目不承诺完全离线、零幻觉、任意格式理解、系统级隔离或全平台生产认证。GitHub Actions 成功也不替代上述宿主核验。
