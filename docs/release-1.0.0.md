# DSH 资料库 1.0.0

首个公开正式版本：为 DeepSeek Harness 提供按工作区隔离的本地原文件库。新工作区自动建库；已有工作区可手动创建或关联。在独立「资料库」菜单中集中管理，对话里随时选择是否参考。

## 下载与安装

- **插件安装包：`dsh-library-1.0.0.tgz`**。在 DSH 插件管理器的本地安装包入口安装；若宿主仅提供目录链接，解压后选择含 `package.json` 的 `package` 目录，以实际宿主入口为准。
- `dsh-library-1.0.0-source.zip`：完整公开源码、测试与开发文档，不是安装包。
- `dsh-library-1.0.0-SHA256SUMS.txt`：上述两份文件的 SHA-256。

安装/更新后完整退出 DSH（含托盘后台进程）再启动并刷新。不要覆盖宿主源码、删除资料目录或修改 profile。升级前联合备份资料目录和 DSH profile。

## 主要功能

- 自选本机存储位置、工作区稳定 ID 关联、统一管理页和搜索筛选。
- 任意格式原件保存；拖放文件/文件夹、递归扫描、居中确认弹窗与串行导入。只复制原件，不修改来源文件。
- 会话资料库/通用模式、显式跨库授权、整份原件独立同意；通过 `library_files` 和 `library_open` 按需交付宿主原生附件。
- 下载、排除/纳入参考、回收/恢复、回收区永久删除，以及先停用后整库删除；破坏性操作要求输入完整名称。
- 删除先持久化意图，部分失败保留待续删状态并阻止恢复残缺库；目录身份与嵌套路径检查避免错误连带删除。

## 兼容性与边界

目标接口为 DSH `0.2.1-rc.3`，声明范围 `>=0.2.1-rc.3 <0.3.0`，Node.js ≥22.13.0；不是所有宿主版本均已实测。管理 UI 首版为中文。

导入不预解析、不 OCR、不全文索引；能保存不代表模型能读取或理解。按需打开时云端模型可能接收整份原文件。撤销同意、排除或切换模式只能约束后续插件交付，不能撤回历史附件或已见内容。具体安全边界与宿主实机核验要求见仓库 SECURITY 与验证文档。
